# assets/

This folder is only for static files used by the website.

## music.mp3 (optional)

To enable background music, drop a file named `music.mp3` into this folder.

- Any playable MP3 works (birthday, cinematic, or a favourite song).
- Keep the file reasonably small (a few MB is fine) so the page loads quickly.
- The music starts only after the visitor taps a button, fades in over ~2 seconds, loops, and has an on-screen toggle.
- If this file is missing, the website simply hides the music control and keeps working — no errors.

No other files are required for the website to run.
